## Sections

- **Navbar** with a *Hire Me* button
- **Hero:** introduction with *Download CV* and *Contact* buttons
- **About Me:** a short bio and personal details
- **What I Do:** skill cards for JavaScript, React, Node.js and MongoDB
- **Resume summary:** an education and experience timeline
- **Let's Connect:** a contact form

## Responsive Design

Two media queries adapt the layout:

| Breakpoint | Behavior |
| --- | --- |
| Desktop (> 992px) | Side-by-side skills, resume, about and footer columns |
| Tablet (576px – 992px) | Skills, resume, about and footer stack vertically with roomy padding |
| Mobile (< 576px) | Everything stacks, including personal info, with tighter padding |

## Tech Stack

- HTML5
- CSS3 (Flexbox, media queries)
- Google Fonts (Open Sans)
- GitHub Pages for hosting
